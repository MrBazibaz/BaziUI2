BAZIUI ARTWORK V6 — DEEP PLUM EDITION

- Individual PNG files with real transparency. No atlas cropping.
- Faceted gem geometry with controlled highlights for 32–64px use.
- Richer satin/leather plum surfaces, raised bronze/gold bevels, deeper controls.
- BaziUI logo and separate underline with centered gemstone.
- Existing approved B emblem and original banner retained unchanged.
- Thin frame assets retained from v5, not thickened.
- Same pixel dimensions for all existing PNG assets as v5.
- One additional composite branding PNG: Branding/BaziUI_Logo_Complete.png.
- Preview/Asset_Overview.jpg displays actual exported files.

LIMITATIONS:
- New assets are rendered programmatically to match the chosen visual direction,
  not direct 3D renders from the concept image. Check at 32px in-game.
- Existing utility icons remain from v5, so depth is not uniform everywhere.
- Existing BaziUI_Emblem.png is larger than the runtime variants; prefer 64/256.
- This is an artwork pack, not an integrated WoW addon.
- For resizable controls use nine-slice / cap insets; avoid stretching corners.
- Check WoW Forever client texture support (PNG vs BLP/TGA) before shipping.
- GitHub was not modified.
